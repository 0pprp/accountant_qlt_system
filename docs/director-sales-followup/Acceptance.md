# قبول متابعة المبيعات

| # | السيناريو | النتيجة المتوقعة | حالة |
|---|-----------|------------------|------|
| 1 | مستخدم بلا `SalesFollowup.Read` | تبويب المبيعات مقفول / لا API | جاهز للاختبار |
| 2 | منح `Read` لمستخدم وإيقافه لآخر | يظهر لأحدهما فقط عبر شجرة الصلاحيات | جاهز |
| 3 | اختيار فرع خارج نطاق المستخدم | 403 BranchForbidden | جاهز |
| 4 | اختيار فرع مصرّح | طلب واحد لكروت الموظفين | جاهز |
| 5 | اختيار موظف | طلب واحد للتفصيل (زبائن مضمّنة) | جاهز |
| 6 | جدول التركيز | بلا طلبات إضافية لكل صف | جاهز |
| 7 | تقييمات منخفضة | بلا أسماء زبائن (anonymize) | جاهز |
| 8 | مصفّر | بيع>0 وواصل≥سعر وباقي≤0 وغير قانوني | جاهز (IsLegal=false حتى SCHEMA) |
| 9 | إيقاف التطبيق | ManageAppBlock؛ login App و start-shift يرفضان | جاهز بعد تطبيق SCHEMA |
| 10 | بروفايل زبون returnTo | رجوع لـ tab=sales | جاهز |
| 11 | تصدير | CSV UTF-8 من الجدول المصفّى | جاهز |
| 12 | Marker | `SalesFollowup_V1_BranchScoped_BatchedDetail` | جاهز |
