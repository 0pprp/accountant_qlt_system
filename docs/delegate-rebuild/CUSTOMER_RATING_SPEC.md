# مواصفة تقييم الزبائن — واجهة المحاسب الرئيسي

التقييم يظهر في **لوحة الإدارة** (`panel-admin-main`) ضمن جدول العملاء تحت عمود **التقييم**  
باسم المستوى فقط (بدون درجة رقمية): ممتاز / جيد / ضعيف / متلكئ / سيء.

لا يُعرض في تطبيق المندوب.

## المصدر

- API: `GET /api/v1/admin/Customers` → الحقل `rating`
- الحاسبة: `Application/Customers/Common/CustomerRatingCalculator.cs`
- الواجهة: `CustomerList.vue` عمود `rating`

## الحدود

| المستوى | أيام مصفّر / متوقعة |
|---|---|
| ممتاز | ≤ 150 |
| جيد | 151–160 |
| ضعيف | 161–179 |
| متلكئ | 180–199 |
| سيء | ≥ 200 |

غير مصفّر: `rate = R × 1000 / (S × D)` بنفس عتبات النسبة المكافئة.
