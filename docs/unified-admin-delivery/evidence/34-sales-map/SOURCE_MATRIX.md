# خريطة المبيعات — مصفوفة المصدر (مثبّتة)

| الحقل | المصدر | القاعدة |
|---|---|---|
| وحدة النقطة | `Order.Id` عبر أهلية SalesRecords | `ApprovalStatus == Approved` |
| إحداثيات | `Order.Location` فقط | صالح إن غير null وضمن المدى وليس (0,0)؛ وإلا «بدون موقع» |
| قوائم المحافظة | `DelegateFollowupDataService.ListActiveListsAsync` على فروع `ProvinceId` | نفس أهلية متابعة المندوبين (40ي + متبقٍ) |
| قانونية | `Customer.IsLegal` | أولوية مطلقة → رمز 3 |
| مستمر | `ActiveCustomerRules.IsActive` (30ي) على آخر تسديد للمبيع | رمز 1؛ ليس قانوني |
| متوقف | غير قانوني وغير نشط | رمز 2 |
| غير محدد | بلا SaleDate وبلا آخر تسديد وليس قانوني | رمز ؟ في «الكل» فقط |
| تقييم/لون | `CustomerRatingCalculator` على أرقام هذا المبيع | ليس تقييم موظف |
| ماليات التفاصيل | مجموع دفعات Order + SellAmount | آخر تسديد = أحدث دفعة لهذا OrderId |
| وهمي | `Customer.IsFakeSale` | لا يُرسم على الخريطة؛ يُحسب بدون موقع |
