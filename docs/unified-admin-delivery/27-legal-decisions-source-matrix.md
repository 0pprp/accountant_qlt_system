## شروط الإدراج في الأسماء القانونية
من `Customers_GetWeakWeekPayers`:
- متبقي > 0
- تسديد 7 أيام ≤ 3.8% من إجمالي البيع
- آخر تسديد ≥ 40 يومًا أو لا يوجد
- استبعاد: `IsLegal`، وهمي، طلب قانونية معلّق، تنازل معلّق، snooze «متواصل» نشط

## قرارات الفرع
| النوع | أثر |
|---|---|
| متواصل | SnoozeUntil = الآن+7 أيام |
| وهمي | IsFakeSale = true + سجل قرار |
| قانونية | يخلق LegalConversionRequest Pending + قرار «طلب قانونية» — لا يضبط IsLegal فورًا |
| تنازل | يبدأ WaiverRequest (مجال 26) |

ملاحظة إلزامية لكل قرار. موافقة المراقب على التحويل: `IsLegal=true` + قرار «قانونية». الرفض يتطلب سببًا.
