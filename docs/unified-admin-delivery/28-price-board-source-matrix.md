# 28 — مصفوفة مصدر لوحة الأسعار

مرجع استكشاف: [استكشاف لوحة الأسعار](6570bd16-e0e3-4dce-b0dc-5d3412ca555f).

## تعريف المجال (من المصدر)
**سجلات إعلان أسعار نصّية/رقمية لكل محافظة** — ليست لوحة صور، وليست محرّر أسعار `Product`، ولا تعيد تسعير Orders.

الكيان القديم: `dbo.PriceBoardEntries`  
الحقول: `ProductName` (نص حر)، `SalePrice`، `DailyInstallment`، `DownPayment`، `TargetCityValue/Name`، تدقيق إنشاء/تحديث.

## الفاعلون
| الطرف | قراءة | كتابة |
|---|---|---|
| المراقب | كل/فلتر محافظة | إنشاء/تعديل/حذف |
| المحاسب الرئيسي | محافظة فرعه فقط | لا |
| موظف المبيعات | محافظة فرعه | لا |
| المدير | API قد يسمح بالقراءة؛ السايدبار يخفيه | لا |

## المسار
شاشة FE `price-board` → `api/director/price-board` → `PriceBoardService` → الجدول  
المستهلك: `sales_employee_application` عبر `api/sales/price-board` (بوابة داخلية حسب المدينة).

## الفلاتر والترتيب
- فلتر اختياري `cityValue` للمراقب؛ الفرع مقيّد بمدينته.
- ترتيب: `UpdatedAtUtc DESC, Id DESC`.
- لا تفعيل/تعطيل/نشر — الوجود = الظهور. حذف نهائي فقط.

## الأثر المالي
**لا يوجد.** لا يمس Products ولا Orders ولا الأقساط.
