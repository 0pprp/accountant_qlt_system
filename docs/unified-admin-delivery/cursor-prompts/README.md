# برومبتات لوحة الإدارة والمبيعات الموحدة

هذه مواصفات تنفيذ لكيرسور، وليست إعلان تنفيذ أو اختبار الخدمات المقترحة. جرى مراجعة سجل التنقل القديم وحراسة الأدوار وملفات الملخص وعمل المتابعين وعقود الاستدعاء، وسجل Management الجديد. بقية التفاصيل تُستخرج مع كل برومبت من ملفاتها؛ لا يُدّعى اكتمال تدقيق كل وظيفة قديمة في هذه الحزمة.

## القرار المعتمد
- لوحة إدارة واحدة للوظائف الإدارية التي يستخدمها المدير والمراقب وغيرهما حسب صلاحيات الحساب.
- وظائف مدير المبيعات ومتابعة موظفي المبيعات ضمن المبيعات.
- الأدوار قوالب افتراضية فقط؛ التبويبات الجاهزة مقفولة/مفتوحة حسب الصلاحيات الفعلية، ولكل إجراء إذن مستقل.
- نفس معلومات وقواعد عمل القديم، بعقود API وكيانات ومعمارية الجديد. لا تشغيل على API القديم.
- لا حذف لشغل شهرين ولا إعادة بناء ما يعمل؛ استكمال وتصحيح الفروق فقط.

## طريقة الاستعمال
أرسل ملفًا واحدًا لكيرسور في كل دفعة. كل ملف يتضمن التعليمات المشتركة كاملة، فلا يحتاج نسخ مقدمة منفصلة. ابدأ 01 ثم 02–04 ثم 05–13، ثم 14–22 ثم 23–31 ثم 32. يمكن تنفيذ المبيعات قبل عمل المتابعين حسب الأولوية بعد 01، لكن 20 يعتمد منطق 02 و06–13 تعتمد05. لا تنفذ هذه الحزمة كلها في أمر واحد دون مراجعة مخرجات كل تبويب.

أرسل مع الملف: «نفّذ هذا البرومبت داخل المشروع، أعد استخدام الموجود بعد التحقق، ولا تنشر إنتاجًا. سلّم الأدلة وحدث Excel وWord.»

## شكل التنقل المستهدف
لوحة الإدارة
- الملخص
- التقييمات
- متابعة المندوبين
- عمل المتابعين: مصادقة البيع / المتدنية / الملاحظات / الزبائن القديمة / ملاحظات المندوبين / الجباية / الموقع المباشر / المسارات
- المهام / مهام اللجنة / ملاحظات التطبيقات / التنازلات
- الأسماء القانونية: الأسماء / طلبات التنازل / سجل القرارات
- لوحة الأسعار / الإعلانات / الفيديوهات التعليمية / أعمال إدارة الفرع والمفوض الموجودة

المبيعات
- نظرة عامة / طلبات البيع / موظفو المبيعات / متابعة المبيعات
- الموقع المباشر / المسارات / المبيعات المنجزة / ملخص المبيعات / المتابعة القانونية

المستخدمون والزبائن وبقية الوظائف الحالية تبقى متاحة وفق نطاق المشروع؛ لا تنسخ صفحاتها في أكثر من module. الأسماء والمسارات canonical تثبت في01 مع aliases آمنة.

## ملاحظات مثبتة تمنع النقل الخاطئ
- FE القديم يخفي الملخص عن المراقب، وملخص المبيعات عن مدير المبيعات. الجديد يترجم ذلك إلى defaults قابلة للتخصيص، ولا يقيد الميزة باسم دور.
- ملخص المبيعات يثبت salePrice؛ لا يكشف مقاييس ملخص الإدارة الأخرى.
- الزبائن القديمة ضمن عمل المتابعين يستدعي LegalFollowups؛ ليس فلتر تاريخ عام.
- فتح صلاحية إجراء وحده لا يبيح قراءة كل بيانات التبويب.
- سجل الجديد يحتوي DelegateFollowup بالفعل: 04 تكملة وفحص لا إنشاء مكرر.
- أرقام legacy listId/DelegateID لا تُنسخ كأنها OrderListId في الجديد دون mapping.
