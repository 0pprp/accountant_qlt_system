## المراحل في التطبيق
| المرحلة | الشرط |
|---|---|
| قيد المتابعة | غير محذوف، ليس مرفوضاً ولا مكتملاً |
| تم البيع — قيد التسديد | Completed والمتبقي > 0 |
| مكتمل التسديد | Completed وقيمة المبيعة > 0 والمتبقي ≤ 0 |
| مرفوض / ملغى | Rejected أو محذوف |

تقدّم التسديد = مجموع تسديدات **الطلب المرتبط نفسه** (`LinkedOrderId`) مقابل `SellAmount`.

## المحلات
- الاسم 2–150، الاهتمام 1–5، الهاتف اختياري عراقي، الملاحظة ≤ 500، الموقع داخل العراق.
- الزملاء يرون الموقع والاسم والاهتمام فقط، داخل مربع ±0.5° وحتى 500 محل. التعديل والحذف لصاحبه فقط.

## الدوام والموقع
- دوام واحد مفتوح لكل مروّج، يبدأ تلقائياً مع أول طلب أو محل.
- الدفعة ≤ 500 نقطة، `clientEventId` إلزامي ويمنع التكرار، النقطة داخل العراق، وقتها بين بداية الدوام −2 د والآن +5 د.
- إغلاق تلقائي لدوام الأيام السابقة عند آخر نقطة أو 23:59:59.
- الحذف بعد 90 يوماً، مرة يومياً.

## الفترات والهدف
- الأحداث = تثبيت محل + إرسال طلب. فجوة 15 دقيقة أو أكثر تقطع الفترة؛ أقل من 3 دقائق بين محلين = «سريع».
- دقائق اليوم = مجموع أطوال الفترات (`PinPeriods.cs:15-16,32-55`).
- الهدف = هدف المروّج أو الافتراضي العام؛ الحالة: حقّق / لم يحقّق / غائب / بلا هدف (`WorkTargetService.cs:56-63`).
- الأيام المنتهية تُجمَّد في `FieldPromoterDays`.

## تنبيه الوقوف
- نصف القطر 150 م ومدة 60 د (قابلة للتعديل 30–2000 م، 5–600 د)، أحدث نقطة ≤ 20 دقيقة.
- يُحل التنبيه عند الحركة خارج نصف القطر أو انتهاء الدوام (`WorkAlertService.cs:32-40,98-108`).
