## تفصيل المجالات الثلاثة

### أ) متابعة المندوبين

| بند | المرجع | الجديد |
|---|---|---|
| وحدة العمل | قائمة مندوب `DelegateID` نشطة | موظف مبيعات `employeeId` / SellerId |
| التنقل | مدينة → بطاقات قوائم → مؤشرات → جدول | فرع → بطاقات موظفين → Dialog |
| مؤشرات | قسط مطلوب، وارد أمس/جمعة، فئات، باقي، قانونية، تحويل، تقييمات لجان، مبيعات بلا جباية | زبائن، متوسط تقييم، تحويلات موظف، جدول تركيز |
| إجراء أساسي | تقييم عامل اللوحة للقائمة (0–10/يوم) | إيقاف تطبيق الموظف (+ manager-rating بلا UI) |
| عقود | `director-delegate-followup/lists|summary|customers|board-operator-rating` | `admin/SalesFollowup/employees*` |

**ما يُعاد استخدامه من الجديد:** أنماط Management shell، Dialog/RTL، صلاحيات منفصلة، عزل الفرع — **ليس** منطق SalesFollowupDataService كبديل للقوائم.

**غير محسوم:** عتبة 40 يوماً موثّقة في قواعد/تعليقات المرجع؛ معادلات التقييم مفصّلة في `CustomerRatingCalculator` — تُنقل حرفياً في التنفيذ لاحقاً دون اختراع.

### ب) عمل المتابعين

مجموعة تبويبات فرعية حقيقية (كل واحد يحتاج برومبت لاحق مستقل):

1. مصادقة البيع (`tab=sales`)
2. المتدنية (`declining`)
3. الملاحظات (`notes`)
4. الزبائن القديمة (`oldCustomers`)
5. ملاحظات المندوبين (`delegateNotes`)
6. الجباية (`collection`)
7. الموقع المباشر / المسارات

**الحكم:** غير موجود في الجديد. ManagementTasks لا يغني.

### ج) الملخص

فلاتر: نوع المبلغ (واردات/صرفيات/سعر بيع/شراء/مشتريات) + شهر + سنة؛ بطاقات فروع كلي/فعلي؛ نقر يوم → drilldown.  
**معادلات الكلي/الفعلي:** غير محسومة في هذا التسليم (لم تُقرأ تفاصيل `GetMatrixAsync` سطراً بسطر) — تُستخرج قبل برومبت التنفيذ.

## سياسة التصحيح (عند الموافقة على التنفيذ لاحقاً)

1. **لا حذف** SalesFollowup ولا ManagementTasks ولا بياناتهما.
2. **فك الربط الخاطئ فقط:** لا تستخدم صفحة موظفي المبيعات كمدخل لـ«متابعة المندوبين»؛ لا تسمِّ المهام «عمل متابعين».
3. **أضف** مسارات/صلاحيات جديدة للمجالات الثلاثة عند التنفيذ بموافقة لاحقة.
4. **لا migration / لا نشر** قبل اعتماد المقارنة والبرومبتات.
5. **لا endpoint جديد** قبل التحقق من إمكانية إعادة استخدام عقود `director-delegate-followup` / `director-follower-ops` / `director-summary` (مع تكييف الأسماء لنطاق النظام الجديد).
