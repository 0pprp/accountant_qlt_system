# تدقيق طلبات البيع — القواعد، المسارات، الفروق عن القديم

## دورة التدقيق

```
المبيعات → طلبات البيع → غير المسند
  → كرت مختصر → تدقيق الطلب (مساحة واحدة)
    → حسابات سابقة | طلبات مكررة
    → أربع بطاقات مطابقة → نتائج المعيار
    → أكشنات (إسناد/رفض/استثناء) بصلاحيات مستقلة
    → بروفايل زبون (مسار مستقل) → عودة للتدقيق (سياق آمن)
```

## قواعد المطابقة (منقولة دون تغيير النتائج)

| مفتاح | قاعدة | بيانات ناقصة |
|-------|-------|--------------|
| tripleName | تطابق الرموز 0,1,2 بعد التطبيع | أقل من 3 رموز |
| phone | تساوي ForMatch (10 أرقام تبدأ بـ7) | هاتف غير صالح |
| fatherGrandfather | تطابق الأب+الجد معًا | نقص أحدهما |
| sonFather | ثنائي الاتجاه | نقص الرموز |

التطبيع للمقارنة فقط. حالات البطاقة: loading / results / noResults / insufficientData / failed. فشل الفحص ≠ صفر.

التشابه ليس إثبات هوية ولا قرابة. لا دمج تلقائي.

## الإسناد والاستثناء

- اليدوي: حالة غير مسند + نطاق فرع + أهلية موظف (CreationStep.Completed + فرع + حساب فعّال) + ConcurrencyStamp.
- التشابه إعلامي فقط للإسناد اليدوي.
- CRM auto-assign: **Not implemented** هذه المرحلة.
- الاستثناء: بوابات حالة من القديم؛ لا يتجاوزها الـUI.

## فروق عن القديم (SalesHaider)

| موضوع | القديم | الجديد |
|-------|--------|--------|
| مخزن غير المسند | لوحات حالة متعددة في Vue ضخم | SalesRequest مستقل عن Order |
| Pending | قد يختلط في الواجهة | ليس مرادفًا لغير المسند |
| evaluate/hits | endpoints قديمة | عقود admin جديدة |
| منع الإسناد عند تطابق | بوابة CRM/يدوي متفاوتة | يدوي غير ممنوع بالتشابه |
| بروفايل | بطاقات مكدسة | تبويبات مربوطة فقط |
| الصلاحيات | أدوار SM | Outside Permissions.All |
